Crime Analytics Visualization Using Machine Learning

CrimeVision is a full-stack data analytics platform that combines a real crime dataset from Indian cities with a Random Forest machine learning model to enable deep exploration of crime patterns, interactive filtering, and real-time crime type prediction.

The project aims to demonstrate how data science and machine learning can assist in understanding crime distribution, identifying patterns, and building predictive intelligence for law enforcement use cases.

ML Features

Dataset

The dataset (crime_dataset_india.csv) contains 40,160 crime records from 2020 across 29 major Indian cities. Each record includes:

  • Report number, dates, time of occurrence
  • City of the incident
  • Crime code and description (21 types)
  • Victim age, gender (M/F/X)
  • Weapon used
  • Crime domain (4 categories)
  • Police deployed, case status

Data Preprocessing

The raw dataset was cleaned and prepared for ML training:

  • Missing Weapon Used (~5,790 nulls) → filled with "Unknown"
  • Date Case Closed — not used as feature (too many nulls)
  • Feature selection — 5 input features chosen
  • Label Encoding applied to all categorical columns
  • Final cleaned dataset exported as cleaned_crime_dataset.csv

Machine Learning

A Random Forest Classifier was trained using scikit-learn:

  • 100 decision tree estimators
  • 80/20 train-test split (random_state=42)
  • Training: 32,128 samples | Test: 8,032 samples
  • Parallel training with n_jobs=-1
  • Prediction target: Crime Description (21 classes)
  • Model persisted with joblib (.pkl files)

Prediction System

The live prediction system allows users to:

  • Select from all real values present in the dataset
  • Submit 5 features through a validated form
  • Receive the predicted Crime Description
  • View prediction confidence percentage
  • See the top 3 predicted crime types with probabilities
  • Handles invalid inputs with informative error messages

Analytics Dashboard

The interactive dashboard provides:

  • 6 summary KPI cards with live data
  • Year-wise crime trend line chart
  • Top 10 crime types and cities (bar charts)
  • Case status, domain, weapon, gender distribution charts
  • Interactive filters (city, year, domain)
  • Sortable city-wise and crime-type data tables
